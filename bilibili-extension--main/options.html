📖 使用说明

1️⃣ 在本仓库根目录启动本地桥接：python mcp_server.py --port 8765（端口与上方设置一致）
2️⃣ 打开本页 → 启用 MCP 服务 → 点「保存设置」，状态点变绿即已连接
3️⃣ 在 AI 客户端配置 MCP 服务器地址：http://127.0.0.1:8765/mcp
4️⃣ AI 即可调用：get_video_info / fetch_danmaku / fetch_comments / fetch_subtitle / word_cloud / get_cookie_status（Cookie 自动从浏览器读取，弹幕自动走 seg.so 全量接口）

⚠️ 隐私声明

开启后将把你的 API Key 以明文形式永久保存在本机浏览器存储（chrome.storage.local）。

这意味着：
· 浏览器重启后 无需重新输入 Key，可直接使用 AI 功能
· Key 只会保存在 本机，不会上传到云端、不会同步到其他设备
· 任何能访问你电脑 / 浏览器数据的人都可能 看到并盗用 你的 Key，请确保设备可信

你可以随时在设置页关闭此选项，已保存的 Key 副本将被 立即删除。
